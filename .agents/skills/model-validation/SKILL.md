# 模型驗證

1. 先確認資料集版本、頁面集合、批次設定、模型與提示詞快照、成功/失敗狀態及計分欄位可比。不能比的批次分開呈現。
2. 讀取既有人工覆核 gold，記錄檔案雜湊與使用的版本。以 `(source, page)` 對齊，按影像 SHA-256 去重並固定代表頁及 gold 覆蓋率；空值或低信心標註依既有評分規則處理。若腳本仍按原始頁面計分，標明原始分母，不得稱為去重準確率。
3. 使用保存的結果與參數化評分命令，明示批次、凍結 gold 及新輸出目錄；評分不組合或覆寫 gold。執行後核對來源 gold 雜湊未變。
4. 明確區分「模型間一致／不一致」與「對人工覆核 gold 正確／錯誤」。回報樣本數、去重後分母、失敗數、主要指標與限制，附必要證據即可。

不得自動修改 gold、將測試資料寫入 few-shot、啟動昂貴 OCR/VLM 或辨識批次。若需求需要這些動作，先回報所需範圍與成本，交由主代理依使用者授權處理。

執行命令、資料路徑與硬編碼風險見 [references/workflows.md](references/workflows.md)；只有實際需要執行或診斷時才讀取。

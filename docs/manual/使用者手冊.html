操作指引

憑證辨識系統使用者手冊

本手冊說明如何將 PDF 或圖片匯入系統，逐頁確認影像外觀，再辨識憑證內容、核對結果並列印。請依「匯入 → 外觀確認 → 掃描清單 → 確認與列印」的順序操作。

步驟 01

匯入檔案

將 PDF 或圖片交由系統處理。多頁 PDF 會依頁碼分頁，逐頁完成外觀確認。

開始前的準備

登入系統並準備要處理的 PDF 或圖片。請先確認文字清晰、頁面完整；若同頁有多張憑證，建議先整理為一頁一張，以便後續確認與辨識。

操作步驟

  1. 開啟「① 匯入」，選擇本次憑證的歸屬公司。
  2. 選擇匯入流程。一般逐頁整理可使用「人工確認優先（快速）」；需要系統先分析方向與版面時，可選「完整自動（方向與版面分析）」。
  3. 將檔案拖曳至上傳區，或點選上傳區選取檔案。每次匯入一個檔案；檔案大小請依畫面提示辦理。
  4. 等候系統分析總頁數並準備頁面預覽。當畫面提示可進行外觀確認時，按「繼續外觀確認」。

多頁檔案如何處理

系統會顯示目前頁碼與總頁數，例如「第 1／3 頁」。先完成第 1 頁的外觀確認，系統才會繼續準備第 2 頁；依此順序處理至最後一頁。分頁只是將 PDF 各頁拆開，不代表辨識內容已經完成。

三頁 PDF 範例
匯入檔案 → 確認第 1 頁外觀 → 確認第 2 頁外觀 → 確認第 3 頁外觀 → 到掃描清單進行辨識。

完成判斷
目前頁面已可在「② 外觀確認」檢視；多頁檔案請持續處理，直到所有頁面都已完成外觀確認。

步驟 02

外觀確認

先把影像調整到文字正向、邊界完整且方便閱讀的狀態，再加入掃描清單。

操作步驟

  1. 在「② 外觀確認」檢查目前頁面，並核對單據類型與歸屬公司。
  2. 若影像橫向或倒置，使用「↺」或「↻」調整方向；每按一次旋轉 90 度。
  3. 若文字只有輕微歪斜，使用「−0.5°／＋0.5°」、滑桿或角度欄微調。先查看預覽，再按「套用」。
  4. 需要去除黑邊或多餘背景時，按「裁切」，拖曳框選要保留的區域，再按「✓ 確認」。
  5. 再次檢查影像與類型，按「確認外觀（加入掃描清單）」。多頁檔案會接著準備下一頁，請逐頁重複以上步驟。
調整項目使用時機操作提醒
方向整張影像橫向或倒置以 90 度為單位旋轉，讓文字朝上。
角度文字或表格輕微歪斜微調累計範圍為 ±15°；預覽後須按「套用」。
裁切影像有黑邊或多餘背景保留框內內容；框外內容會從目前影像移除。
復原調整結果不合適按「↶ 復原」回到剛進入外觀確認時的影像。

送出前請逐項檢查

  • 文字方向正確，沒有明顯傾斜。
  • 日期、號碼、統編、金額及重要註記都在影像範圍內。
  • 裁切沒有切掉憑證邊緣的必要資訊，單據類型與公司也已核對。

裁切提醒
裁切會取代目前影像，不會自動新增另一張憑證。若只想放棄角度預覽，可按「取消預覽」；已套用的微調可使用「還原微調」。

步驟 03

掃描清單

外觀確認完成的憑證會加入「③ 掃描清單（待提取）」，供您集中檢視並執行內容辨識。

操作步驟

  1. 開啟「③ 掃描清單（待提取）」，核對要處理的影像是否都已列入。
  2. 只處理其中一張時，按該張憑證的「辨識此張」。需要處理清單內全部待提取憑證時，按「一鍵提取全部」。
  3. 等候系統提取內容。辨識完成後，前往「④ 確認」檢查辨識結果。

憑證會出現在哪裡

處理階段查看位置下一步
尚未確認外觀② 外觀確認調整影像並確認外觀。
已確認外觀，待辨識③ 掃描清單辨識此張或一鍵提取全部。
已辨識，待核對④ 確認的待確認範圍核對欄位、修正並確認。
辨識結果已確認④ 確認的已確認範圍開啟列印報告。

匯入並確認外觀的憑證會保存在系統中，畫面則依處理階段顯示。某張憑證完成辨識後，請到「④ 確認」查看；掃描清單主要顯示等待提取內容的憑證。

需要補查時

  • 找不到剛匯入的頁面時，先確認該頁是否已按「確認外觀（加入掃描清單）」。
  • 多頁 PDF 尚未全部出現在清單時，回到匯入進度或外觀確認，繼續處理剩餘頁面。
  • 辨識中請等候畫面更新；若畫面顯示失敗訊息，先查看原因，再依提示處理。

完成判斷
要處理的憑證已完成內容辨識，並可在「④ 確認」開啟核對。

步驟 04

確認並列印

依原始憑證核對辨識內容，完成確認後再開啟列印報告。

核對與確認

  1. 開啟「④ 確認」，在待確認範圍選取一張憑證，對照影像與辨識結果。
  2. 核對日期、憑證號碼、買賣方資訊、統編、金額與明細等欄位。實際顯示項目依單據類型而定；如有錯誤，直接修正。
  3. 尚未核對完畢時，按「儲存草稿」。核對完成後，按「確認」儲存並確認這張憑證。
  4. 確認畫面顯示「已確認，可列印」，再按「列印」開啟報告。
操作結果
儲存草稿保存目前修正，憑證仍待確認。
確認保存並確認目前的辨識內容。
列印開啟已確認版本的列印報告。

列印報告

開啟報告後，使用瀏覽器列印功能，選擇印表機、紙張方向與頁面範圍，查看預覽後送出。若要保存電子檔，可在列印目的地選擇「另存為 PDF」或電腦提供的 PDF 印表機。

常見處理方式

按了儲存草稿，為什麼仍不能列印
草稿只保存修正。請完成核對並按「確認」，待畫面顯示「已確認，可列印」後再列印。

修改後，為什麼顯示需要重新確認
列印使用的是已確認版本。若內容已修改，請再次按「確認」；若系統提示版本已變動，請重新載入並核對後確認。

完成判斷
所有要交付的憑證都已確認，且列印或另存的報告內容、頁數與預覽一致。

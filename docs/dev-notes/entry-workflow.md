# 分錄編輯與入帳確認

辨識確認與分錄確認是兩個獨立步驟。使用者可先確認憑證欄位，即使尚未建立分錄、科目仍待核對，或借貸尚未平衡。這項確認表示憑證內容已覆核，不表示它已可納入正式帳務。

## 編輯分錄

分錄可以新增、修改及刪除。每列記錄一個科目、一個金額及借方或貸方方向；科目可手動輸入，也可參考該公司的建議。手動科目不會因此改動公司的科目表。金額為 0 是有效值；欄位缺漏時仍可保存草稿，但不能確認入帳。空白分錄列可留在草稿中，確認前須移除或補齊。

辨識明細是否存在，依單據類型或實際明細判斷；有明細的憑證仍可產生分錄。明細缺少科目或尚待核對時，不會發布品名科目共用規則，也不會阻止辨識確認。

## 使用 AI 候選

一般非日記帳、非附件單據可選擇請 AI 提出分錄候選。候選先供預覽，使用者可採用整組候選或捨棄。採用前會比對現有草稿；採用時以候選整組取代草稿，不會附加在原分錄後，也不會直接覆寫目前分錄。候選不會在來源欄位或明細改變後繼續有效。

## 確認供入帳

只有辨識已確認的憑證可確認分錄。確認前，每列都須有完整科目代碼、科目名稱、金額與借貸方向，並且借貸總額差小於 0.01。分錄確認後才可納入日記帳及正式傳票；這些頁面會顯示被排除的憑證數。報表摘要維持原有辨識確認統計條件，不要求分錄已確認。

編輯分錄會使該分錄的入帳確認失效。修改辨識欄位、公司、明細或影像會使辨識與分錄兩種確認都失效。既有憑證的分錄會以草稿遷移，須由使用者檢視並重新確認後才能納入帳務。

## 部署

部署前先備份資料庫與設定，完成版本更新後完整重啟應用程式，讓資料庫遷移執行。舊分錄不會自動視為已確認；請在重新納入日記帳或正式傳票前逐筆檢視與確認。
